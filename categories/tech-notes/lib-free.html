图书馆座位自动预约工具
lib-free
✦ 2026-07-27 ✦ 5 min read #Node.js #ZJUAM #AES

浙江大学紫金港主馆图书馆的座位预约系统有一个网页端，但它没有「发现空座自动提醒」的功能。 于是写了一个小工具，0.5 秒轮询一次，发现空位立刻自动预约，预约成功通过钉钉通知。

概述

GitHub 仓库： github.com/GalateaYe749/lib-free
许可： MIT
技术栈： Node.js · login-zju · CryptoJS (AES-128-CBC)

lib-free 是一个纯 Node.js 的命令行工具，无需图形界面，在服务器、树莓派、或任何能跑 Node.js 的机器上都能用。整个代码只有一个文件 index.mjs，依赖只有 login-zju 一个库。

功能

  • 自动登录 — 通过浙大统一身份认证（ZJUAM）登录图书馆预约系统
  • 0.5 秒轮询 — 每 500ms 查询一次指定区域的座位状态
  • 自动预约 — 发现空闲座位立刻预约第一个，无需人工干预
  • 钉钉通知 — 预约成功后通过钉钉机器人发送通知（可选）
  • 22:30 自动退出 — 图书馆系统在此时间后关闭 API
  • 多区域支持 — 可同时监控多个阅览室区域

技术原理

这个工具的核心逻辑可以拆成四个步骤：

1. 认证

使用 login-zju 库完成浙大统一身份认证（ZJUAM）登录，然后通过 CAS 协议获取图书馆系统 booking.lib.zju.edu.cn 的票据，交换得到 Bearer Token。这个 token 放在请求头的 Authorization: bearer{token}（注意 bearer 后面没有空格，有空格会触发 10001 错误）。

2. 获取时段 ID（Segment）

不同于之前很多人采用的硬编码 segment 方式，每次运行时会先调用 /api/Seat/date 接口获取今日可用的时段列表。每个时段有一个唯一的 id（例如 1554019），这个 id 就是后续查座位和预约时要用到的 segment。不同日期的 segment 不同，必须实时获取。

3. 轮询与预约

拿到 segment 后，每 500ms 调用 /api/Seat/seat 查询空闲座位（status = "1"）。一旦发现有空闲座位，立即对第一个座位发起预约请求。

预约请求需要 AES-128-CBC 加密。加密参数：

  • 密钥： YYYYMMDD + reverse(YYYYMMDD)，例如 2026072772706202
  • IV： 固定字符串 ZZWBKJ_ZHIHUAWEI
  • 明文： {"seat_id":"...","segment":"..."}（仅需两个字段）
  • 密文放在： POST /api/Seat/confirm { aesjson: 加密结果, authorization: "bearer{token}" }

Bearer Token 的获取方式比较特殊：monkey-patch globalThis.fetch，拦截 BOOKINGLIB.fetch 发出的 Authorization header。

4. 通知

预约成功后通过钉钉自定义机器人发送通知。使用 HMAC-SHA256 签名方式，需要在钉钉群中创建一个自定义机器人，获取 Webhook 地址和加签密钥。

快速使用

以下是从零开始运行这个工具的步骤：

  1. STEP 1 · 安装 Node.js
    确保你的电脑上有 Node.js 18+，没有的话去 nodejs.org 下载。
  2. STEP 2 · 下载工具
    从 GitHub 下载 ZIP：github.com/GalateaYe749/lib-free，解压后进入 lib-free-main 文件夹。
  3. STEP 3 · 安装依赖
    npm install，只需安装 login-zju 一个库。
  4. STEP 4 · 配置个人信息
    复制 .env.example 为 .env，填入你的学号和浙大统一身份认证密码。
    可选：配置钉钉 Webhook 和加签密钥，用于接收预约成功通知。
  5. STEP 5 · 修改监控区域（可选）
    打开 index.mjs，修改 AREAS 数组来指定要监控的阅览室区域。
    默认监控二楼南（58）和二楼北（59），可改为三楼东（60）/ 三楼南（61）等。
  6. STEP 6 · 运行
    node index.mjs，脚本会自动登录、轮询、预约。

技术细节

API 调用链

POST /api/Seat/date          ← 获取今日时段（得到 segment id）
  { build_id: "58" }

POST /api/Seat/seat          ← 查座位（每 0.5 秒轮询）
  { area, segment, day, startTime, endTime }

POST /api/Seat/confirm       ← 预约（AES-128-CBC 加密）
  { aesjson: encrypted, authorization: bearer{token} }
  // 加密内容: {"seat_id":"6046","segment":"1554019"}

区域 ID 对照

二层南 = 58 (32座)    二层北 = 59 (176座)
三层东 = 60 (48座)    三层南 = 61 (112座)
三层北 = 62           四层东 = 63
四层南 = 64           四层西 = 65
四层北 = 66           五层东 = 67

座位状态码

"1" → 空闲    "2" → 已预约    "3" → 锁定
"4" → 临时离开  "6" → 使用中

做这个工具的动机

图书馆的座位预约系统虽然能用，但需要手动刷新页面查看空位，热门时段经常一刷新就被抢走了。 这个工具的核心思路很简单：让机器替人盯着。0.5 秒的轮询间隔基本能保证在座位释放的第一时间发现并预约。

最大的技术难点是逆向 AES 加密参数。图书馆前端用的 CryptoJS，密钥由日期动态生成。通过分析前端 JS bundle 找到了加密函数和密钥生成规则，才让自动预约成为可能。
