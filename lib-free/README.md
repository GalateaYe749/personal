# 📚 浙江大学图书馆 空闲座位自动监控+预约

一个 Node.js 脚本，自动监控紫金港主馆图书馆的空闲座位，**发现空位立即帮你预约**。

---

## 它能做什么？

1. 🔍 每 **0.5 秒** 查一次指定区域的座位
2. 🎯 发现空闲座位 → **自动预约第一个**
3. 🔔 预约成功 → **钉钉通知你**
4. 🛑 **22:30 自动退出**（图书馆系统会关 API）

---

## 需要什么？

- 一台 **24 小时开机的电脑/服务器**（树莓派、云服务器、旧笔记本都行）
- **Node.js 18+**（如果不确定，往下看怎么装）
- 一个 **浙大统一身份认证账号**（学号+密码）

---

## 🚀 快速开始（5 分钟搞定）

### 第一步：安装 Node.js

> 如果你的电脑已经有 Node.js（用 `node --version` 看一下，版本≥18 就行），跳到第二步。

**Windows / Mac：**
去 https://nodejs.org 下载 LTS 版本，一路「下一步」安装。

**Linux（Ubuntu/Debian）：**
```bash
sudo apt update
sudo apt install nodejs npm -y
node --version   # 确认 ≥ 18
```

### 第二步：下载本项目

从 GitHub 下载 ZIP 压缩包：

👉 https://github.com/GalateaYe749/personal/archive/refs/heads/main.zip

下载后解压，你会得到一个 `personal-main` 文件夹，里面有一个 `lib-free` 子文件夹。

进入那个 `lib-free` 文件夹，后面的操作都在这里面做。

```bash
# 例如解压到 Documents 下
cd ~/Documents/personal-main/lib-free
```

### 第三步：安装依赖

```bash
npm install
```

这会在当前文件夹生成一个 `node_modules` 文件夹，里面是运行需要的代码。

> ⚠️ 如果报错 `npm: command not found`，说明没装 Node.js，回去看第一步。

### 第四步：配置个人信息

```bash
cp .env.example .env
```

然后用记事本/编辑器打开 `.env` 文件，填上你的信息：

```bash
# 你的学号
ZJU_USERNAME="3230100000"
# 你的浙大统一身份认证密码
ZJU_PASSWORD="改成你的密码"

# 下面两行是钉钉通知（不想收通知可以不填）
DINGTALK_WEBHOOK="https://oapi.dingtalk.com/robot/send?access_token=你的token"
DINGTALK_SECRET="SEC你的密钥"
```

### 第五步：配置要监控的区域（可选）

打开 `index.mjs`，找到第 30 行附近的 `AREAS` 数组：

```javascript
const AREAS = [
  { id: "58", name: "二层南", seats: 32 },
  { id: "59", name: "二层北", seats: 176 },
];
```

想监控哪些区域就留哪些，不想要的就删掉。区域编号：

| 区域 | id | 座位数 |
|------|----|--------|
| 二层南 | 58 | 32 |
| 二层北 | 59 | 176 |
| 三层东 | 60 | 48 |
| 三层南 | 61 | 112 |
| 三层北 | 62 | — |
| 四层东 | 63 | — |
| 四层南 | 64 | — |
| 四层西 | 65 | — |
| 四层北 | 66 | — |
| 五层东 | 67 | — |

例如只看三楼：就改成
```javascript
const AREAS = [
  { id: "60", name: "三层东", seats: 48 },
  { id: "61", name: "三层南", seats: 112 },

```

## 📌 钉钉通知设置（可选）

想收到预约成功通知的话：

1. 打开钉钉，建一个**群聊**
2. 群设置 → 智能群助手 → 添加机器人 → 选择「自定义」
3. 复制 Webhook 地址，填入 `.env` 的 `DINGTALK_WEBHOOK`
4. 如果选了「加签」，把 SEC 开头的密钥填入 `DINGTALK_SECRET`

## ❓ 常见问题

**Q：报错「登录失败」？**
A：检查 `.env` 里的学号和密码是否正确。

**Q：报错「登录失败：connect ECONNREFUSED」？**
A：校园网需要连接 ZJUWLAN 或 VPN。

**Q：约完以后怎么签到？**
A：到图书馆后，在闸机刷校园卡入馆即可自动签到。或者打开预约系统的「我的预约」页面扫码签到。

**Q：可以同时监控多个区域吗？**
A：可以，`AREAS` 数组里加几个就监控几个。

**Q：约到座位以后脚本还在跑吗？**
A：约到第一个座位后就自动退出了，不会重复预约。

## 🔒 安全说明

- 账号密码只保存在你自己电脑的 `.env` 文件中
- 所有通信使用 HTTPS 加密
- 不会向任何第三方发送你的数据（除了钉钉通知，那是你自己配的）
- 建议不要把这个脚本放在公共电脑上

---

## 📝 技术原理

1. 通过 `login-zju` 库完成浙大统一身份认证（ZJUAM）
2. 拿到认证票据后，交换获取图书馆系统的 Bearer Token
3. 调用 `/api/Seat/date` 获取今日可用时段的 segment ID
4. 每 0.5 秒轮询 `/api/Seat/seat` 查空闲座位
5. 发现空闲 → AES-128-CBC 加密预约请求 → 调用 `/api/Seat/confirm` 预约
6. 预约成功 → 钉钉通知 → 退出
